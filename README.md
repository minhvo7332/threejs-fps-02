MERIDIAN PROTOCOL — a round-based tactical FPS in the Foundry Yard: plant the spike at Site A or B or eliminate Hollow, earn money each round and spend it in the buy menu, and out-aim bots that route, hold corners and react to what they see and hear.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Click to play: WASD to move, mouse to look, click to fire, R to reload, G for a frag grenade, E (hold) to plant the spike on site, B for the buy menu.
